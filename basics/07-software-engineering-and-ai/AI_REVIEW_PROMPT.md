# Artificial Intelligence (AI) review prompt

Review this code as both a senior software engineer and a skeptical reviewer of AI output. Score correctness, interface design, exception semantics, testability, bounded behavior, and explanation for 100 points. Ask five follow-ups about timeouts, retry storms, idempotency, exception preservation, and how to validate AI-generated dependencies. Do not replace the code before the defense. Below 85 is not interview-ready.
