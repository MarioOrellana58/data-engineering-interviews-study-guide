# AI review prompt

Run a 20-minute senior data-engineering deep dive using the README, `homework.md`, and test output. Ask one question at a time and branch from each answer. Test consistency, personal ownership, scale math, architecture, failure recovery, cost, and stakeholder judgment. Score evidence, depth, decisions, operations, and communication from 0–20. Do not embellish the student's experience. End with three precise improvements; below 85 is not interview-ready.
