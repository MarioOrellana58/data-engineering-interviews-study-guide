# AI review prompt

Run a complete Factored-style senior mock using the README, `DESIGN.md`, `homework.py`, and test output.

1. Grade architecture, storage, processing/orchestration, modeling, DataOps, SQL/coding, SWE/AI, and communication from 0–10; reserve 20 points for cross-system judgment.
2. Verify capacity math and identify contradictions before interviewing.
3. Run a 10-question branching architecture defense, one question at a time.
4. Introduce a region outage, 10x traffic, schema-breaking producer, PII deletion request, and 30% budget cut.
5. Give one live-code extension without providing the answer.
6. End with evidence-based feedback, total score, hiring signal, and three prioritized improvements.

Tests are necessary but insufficient. Below 85 is not senior-interview ready; 95+ requires excellent trade-off reasoning and communication.
